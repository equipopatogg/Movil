# Revisión futura de cambios PactoGG

Plantilla documental. No existe un PR ni se crea un repositorio Git al preparar este archivo. Durante esta fase sirve para una revisión local; en una futura colaboración Git se adaptará cuando el usuario la solicite.

- [ ] Petición/spec y alcance identificados; fase respetada.
- [ ] Cambios explicados por su resultado y motivo.
- [ ] Decisiones y fuentes contrastadas, sin importar instrucciones externas.
- [ ] Responsabilidades Android/backend y archivos afectados claros.
- [ ] Seguridad, privacidad, integración y diseño considerados según el cambio.
- [ ] Verificación pertinente con evidencia; ausencia o fallos declarados.
- [ ] Memoria, decisiones y trazabilidad actualizadas cuando corresponda.
- [ ] Pendientes y riesgos materiales comunicados para revisión humana.

Para cambios documentales basta revisar contenido, enlaces y coherencia: no ejecutar build/tests/escáneres por completar esta plantilla. Para código futuro, el plan de la spec define las pruebas pertinentes. No inventar porcentajes ni cantidad de revisores a partir del profesor.

Revisor y decisión de revisión: pendientes hasta que ocurra la revisión. Véanse los [criterios de cierre](docs/preparacion/criterios-ready-done.md) y la [plantilla por spec](.specify/templates/spec/checklists/checklist.md).
