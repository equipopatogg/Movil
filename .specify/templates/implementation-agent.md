# Perfil futuro de implementación por spec

Esta plantilla está fuera de .opencode/agents para que no se descubra como agente activo.
Antes de crear el perfil: registrar la instrucción que retoma implementación, spec/plan/tasks acordados, rutas editables, dependencias y criterios de prueba.
Definir herramientas y permisos mínimos por tarea; no trasladar permisos de descarga, firma, despliegue o cuentas por el hecho de autorizar código.
Reutilizar skills locales pertinentes; seleccionar externas mediante el registro de descubrimiento y referencia fijada.
Entregar cambio acotado, verificación real, limitaciones y memoria. Los dobles de prueba están permitidos; no presentar datos o autenticación simulada como implementación real.
No heredar la prohibición genérica de fakes del backend del profesor para impedir pruebas aisladas.

Gate documental futuro: cambio concreto y archivos/artefactos delimitados en spec.md, plan.md, tasks.md y checklists/checklist.md; aprobación con Estado/Revisores/Fecha/Detalle; entradas y decisiones necesarias resueltas. Gate de cierre: criterios con evidencia real, resultados omitidos/fallidos visibles, aceptación diferenciada y memoria por fase con Estado, Decisión/motivo, Deuda, A evitar y Slice actual/siguiente paso. La preparación actual no satisface el gate de ejecución por crear este archivo.
