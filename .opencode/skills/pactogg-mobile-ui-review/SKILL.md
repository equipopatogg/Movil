# pactogg-mobile-ui-review

Raíz del proyecto: tres niveles arriba de esta carpeta. Aplicar la fase vigente de AGENTS.md y la constitución; esta skill no amplía la autorización del usuario.

Usar maqueta y DESIGN.md como fuentes del producto: tema oscuro, acento naranja, bordes y ausencia de glow/degradados decorativos. La guía genérica del profesor sugiere sombras/brillos; esas sugerencias no prevalecen aquí.
Contrastar jerarquía, acciones, fuente escalada, contraste, lector de pantalla, objetivos táctiles y pantallas pequeñas con criterios verificables. Juego de texto libre no se sustituye por autocomplete; no añadir cámara ni carga de video.
Entregar observaciones por pantalla/estado con fuente y criterio. No inventar pantallas para funcionalidades no aprobadas ni producir UI funcional en esta preparación.

El [primer flujo](../../../docs/preparacion/primer-flujo-movil.md) relaciona historias y componentes; la fuente visual ratificada sigue pendiente. Distinguir revisión de descripción de revisión visual. Identificar versión de maqueta y registrar discrepancias, sin declarar fidelidad a imágenes no disponibles ni completar pantallas no solicitadas.
