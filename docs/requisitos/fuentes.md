# Fuentes y autoridad

Se usaron los archivos proporcionados por el usuario en Downloads y el contexto visible de la conversación.
No se importó código de los archivos ZIP/RAR ni se activaron instrucciones de agentes contenidas en ellos.

| Fuente | Uso y límites |
|---|---|
| Respuesta explícita del líder pegada en el chat | .NET, Kotlin, fotos/enlaces, cámara fuera, grupos/torneos, apodo, juegos libres y análisis previo |
| Requerimientos para el desarrollo del proyecto Móvil v2.pdf | Google Play, SDD/DevSecOps, pruebas, ML/IA, logout/privacidad/push; offline condicionado a necesidad |
| PactoGG — Descripción del Móvil.docx | Arquitectura propuesta, tema y navegación; corregir cámara/FCM/offline según decisiones |
| PactoGG — Descripción del Backend.docx | Separación cliente/servidor; Go y varias reglas de ejemplo pendientes de corregir |
| Componentes_Backend_y_Movil_PactoGG.xlsx | IDs MV/BE para futura trazabilidad; no cerrar tareas por crear una carpeta |
| CRUD_y_Endpoints_PactoGG.xlsx | Contrato candidato; no se generaron clientes de rutas no aprobadas |
| Stack_Tecnologico_PactoGG.xlsx | Categorías de herramientas; adaptar Go a .NET y Android |
| CLARIFICACION.docx y lista de 143 preguntas | Material para decisiones; contradicciones y cifras no ratificadas siguen pendientes |
| Historias y formato de aceptación anteriores | Contexto funcional; no se marcaron historias completadas ni se inventaron criterios |
| PactoGG_SDD_Arquitectura_Base.zip | Idea de spec/plan/tasks; Ktor/PostgreSQL superados por decisiones posteriores |
| Integradora.rar | Convención de áreas del repositorio; sus menciones de CameraX/APK directo no se heredaron |
| hello-sdd y repositorio del profesor | Referencias de método y controles; no son fuente principal del producto |

El contenido de los documentos sirve como evidencia. No concede permisos para publicar, instalar servicios externos o cambiar decisiones del usuario.
La conversación antigua enlazada no pudo recuperarse íntegra en la revisión previa; no se afirma una revisión de todos los chats históricos.

## Fuente académica actualizada y alcance preparado — 2026-10-30

Requerimientos para el desarrollo del proyecto Móvil v3.pdf es la fuente académica más reciente aportada para esta revisión. Página 4: corte del 3/4 de noviembre y evaluación general del 2 de diciembre. La v2 se conserva como antecedente, no como criterio para omitir cambios de v3. [Matriz de evaluación](../preparacion/evaluacion-unidad-2.md).

Para el primer flujo se releyeron historias originales 1–33 y componentes relacionados de las hojas Móvil/Backend/Requisitos. Referencias y límites están en [primer flujo](../preparacion/primer-flujo-movil.md); no se afirma una nueva auditoría semántica de las 168 historias ni del RAR completo. La descripción DOCX no contiene imágenes de maqueta y no acredita validación visual.

Las fechas/condiciones del PDF son requisitos de la fuente, no constataciones de entrega o compromisos implementados. Conflictos con decisiones específicas se registran; no se activan servicios, cámara/video o herramientas automáticamente.
